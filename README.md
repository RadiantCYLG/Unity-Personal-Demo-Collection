1.委托和事件的区别

事件不能在类的外部进行赋值（但可以在外部使用复合运算符）；

事件不能在外部调用执行，委托则在哪都可以；

事件不能作为临时变量使用



2.反射是.Net提供的机制，是指运行中的程序集获取和操作其他程序集或自身程序集的元数据（类型Type以及类型中的字段、属性、方法、特性）的能力



3.继承抽象类或接口

如果继承的抽象类中有抽象方法(抽象方法没有方法体），必须重写其抽象方法（override重写）

类继承接口后，必须实现接口中的所有成员，并且所有成员要用public修饰



4.接口默认使用public修饰，不能使用private修饰。当接口中的成员被protected修饰时，继承接口，需要显示实现成员，且实现的成员不能使用访问修饰符修饰。
